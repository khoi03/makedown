# Memo task

Using the executive summary in `{{summary}}`, draft a short stakeholder memo for
the leadership team.

Create a new file `stakeholder-memo.md` at the workspace root with exactly:

1. A one-line subject.
2. Three short paragraphs: what happened this quarter, the single biggest risk,
   and the one action we are taking next quarter.

Keep it under 150 words. Do not change any other file.
